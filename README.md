## Featured Projects

### 🫁 [SmokeStat India — Healthcare Analytics Platform](https://github.com/DeadAlmighty/Smoke_Stat)
> Django · PostgreSQL · Plotly · Chart.js · Statistical Modeling

A full-stack epidemiological analytics platform built on a synthetic cohort of **9,000 individuals across 30 Indian states**. Computes a **2.98× disease risk ratio** for smokers vs. non-smokers using chi-square testing, pack-year proxy modeling, and age-stratified analysis. Features a dark-themed interactive dashboard with 9 chart types — heatmaps, grouped bars, doughnuts — all aggregated at the PostgreSQL level with zero Python-side loops over large querysets.

---

### 🛍️ [Mall Customer Analytics — DM & Data Warehouse Capstone](https://github.com/DeadAlmighty/Mall-Customer-Analytics)
> Python · Scikit-learn · Pandas · MLxtend · Matplotlib · Seaborn · Jupyter

End-to-end data mining pipeline covering **K-Means clustering** (5 segments, Elbow Method), **SVM classification** (62.94% accuracy), regression, and **Apriori association rule mining** (99% confidence rules). Includes a **Star Schema Data Warehouse** design with full OLAP operations (roll-up, drill-down, slice, dice) built as a university capstone.

---

### 🗺️ [Pune Seva Sahayog — Civic Services Portal](https://github.com/DeadAlmighty/Pune-Seva-Sahyog)
> HTML · CSS · JavaScript · Geolocation API

A single-page civic-service app covering **34 services across 10 categories** for Pune residents. Supports **English, Hindi, and Marathi**. Uses the **Haversine formula** with the browser Geolocation API to calculate real-time nearest-facility distances.

---

### 🎮 [Snake & Ladder — Tkinter Game](https://github.com/DeadAlmighty/python_game)
> Python · Tkinter

A GUI-based Snake & Ladder game built in Python with Tkinter — an early project focused on event-driven programming and state management fundamentals.
